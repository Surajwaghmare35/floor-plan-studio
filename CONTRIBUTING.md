# Contributing

Thanks for helping improve Floor Plan Studio.

## Development

1. Edit `index.html` (single-file app: HTML + CSS + JS).
2. Open it in a browser or serve with `python3 -m http.server`.
3. Keep changes focused; prefer small PRs.

## Guidelines

- No analytics or tracking by default.
- Do not add proprietary / company branding.
- Prefer vanilla JS (no build step) unless there is a strong reason.
- Test share links (`mode=view`, `#p=...`, `?planUrl=`) after storage or boot changes.

## Pull requests

Describe **why** the change helps users. Screenshots help for UI work.
